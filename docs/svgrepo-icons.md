# SVG Repo icon assets

The launcher ships these locally stored monochrome SVGs from SVG Repo. Their SVG Repo pages identify each asset as CC0/Public Domain:

- Settings gear: https://www.svgrepo.com/svg/185069/settings-gear
- Gamepad: https://www.svgrepo.com/svg/520746/gamepad
- Download arrow: https://www.svgrepo.com/svg/66214/download-arrow
- Database storage: https://www.svgrepo.com/svg/384415/database-storage

The files are used as CSS masks so their color follows the launcher theme. Attribution is not required for these CC0 assets; SVG Repo's licensing page recommends a courtesy link: https://www.svgrepo.com/page/licensing.
