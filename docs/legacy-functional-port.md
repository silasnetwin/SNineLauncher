# Legacy functional port audit

Audit date: 2026-10-15. The legacy tree was inspected read-only at `C:\Users\silas\Documents\SNineLauncher - Kopie`. No legacy files or processes were changed. Credential/key files were intentionally excluded from inspection. The legacy Cargo package identifies itself as `s9lab-launcher` 1.0.10; its source license is All-Rights-Reserved. This document records behavior and contracts only. No legacy implementation code is copied into this repository. This audit is historical and predates current authentication, Minecraft installation/launch, content-management and profile-backup work; do not use its status column as current release status.

## Safe port order

1. Local profile/settings/activity schema and typed IPC (in progress; see [architecture](architecture.md)).
2. A versioned SNine manifest contract and provider allow-list, confirmed against current backend ownership.
3. Persistent download jobs and a transactional install plan using only verified manifest entries.
4. Runtime resolution/validation, then cached launch configuration and process lifecycle.
5. Microsoft/Minecraft authentication using OS credential storage, then authenticated SNine API integration.
6. Content, cosmetics, backup/restore, and launcher update channels after their contracts and keys are verified.

The legacy app is a behavioral reference, not a dependency or source of truth for production endpoint availability. Do not migrate legacy secrets. Future data migration must be copy-only, opt-in, and path-validated.
